# 전기공사기사 기출문제은행

2021~2026년 총233문항을 제공하며, 첨부 HTML의 기존189문항(q001~q189), 정답·해설·36개 도면 연결과 기존 학습 화면을 보존한 웹앱입니다. 사용자가 명시적으로 요청한 내용 정정은 `src/question-corrections.json`에 전후 값과 근거를 기록합니다. 원본은 `backups/original.html`에 보관했습니다. Firebase 설정 없이도 게스트 학습·IndexedDB 저장·JSON/CSV 백업·PWA 오프라인 학습을 사용할 수 있습니다.

현재 상태: 로컬 구현 및 자동 테스트 완료. 사용자 제공 웹 앱 설정을 Firebase 프로젝트 `quiz-8e834`로 반영했습니다. Google 공급자 활성화 및 비로그인 Firestore 읽기·쓰기 차단을 실제 API에서 확인했습니다. Google 계정 실제 로그인과 게시된 보안 규칙 전체의 일치 검증은 아직 완료하지 않았으며, GitHub Pages 공개 배포를 완료했습니다. **[문제은행 열기](https://oper5232.github.io/Public/electrical-quiz/)** · [배포 기록](docs/DEPLOYMENT.md). 공개 사이트의 게스트 학습·기록·PWA 검사9개도 통과했습니다. Firebase 연동 코드와 소유자별 보안 규칙은 포함되어 있습니다. 에뮬레이터 테스트를 실서비스 검증으로 해석하면 안 됩니다. Google Analytics는 초기화하지 않습니다.

## 실행

Node.js 22와 Python 3를 권장합니다.

```sh
npm ci
npm test
npm run build
npm run serve
```

브라우저에서 `http://localhost:4173/`을 엽니다. HTML 파일을 파일 탐색기에서 직접 열면 모듈·서비스워커가 동작하지 않습니다. 실제 배포는 HTTPS가 필요합니다. Firebase SDK를 빌드 결과에 포함하므로 PWA 최초 캐시 후 오프라인에서 외부 CDN을 요청하지 않습니다.

홈에서 **학습 모드 → 실기 · 단답 / 빈칸 채우기**를 선택합니다. 제공 노트에 연결된233문항(단답150/빈칸83)을 답안 작성 → 모범답안 확인 → 직접 정오답 판정으로 학습합니다. 객관식과 통계·미응시·오답을 구분하며 작성 답안도 저장·동기화합니다. [사용법·자료 반영 내역·새 실기 문항 추가](docs/PRACTICAL.md)를 참고하세요.

## Firebase 연결

구체적 절차는 [설정 안내](docs/SETUP.md)를 참조하세요. 설정 전에는 로그인 버튼이 비활성화되고 ‘클라우드 미설정’이 표시됩니다. 유료 플랜이나 결제 계정을 활성화하지 않습니다.

## 기록 모델

각 채점은 무작위 고유 이벤트 ID를 한 번 발급하고 IndexedDB 트랜잭션으로 답안과 함께 저장합니다. 동일 ID를 Firestore 문서 ID로 사용하므로 재전송해도 풀이 횟수가 늘지 않습니다. 다른 시험에서 다시 풀면 새 이벤트가 생깁니다. 기록 전체를 덮어쓰지 않고 이벤트를 합집합으로 병합합니다.

Firestore 경로는 `/users/{Firebase UID}/events/{eventId}`입니다. `attempt`, `star`, `legacy`, `session` 이벤트에서 통계와 최근 20개 정오답 이력을 계산합니다. 계정 전환 시 IndexedDB 소유자도 변경하며 게스트 기록을 자동으로 다른 계정에 섞지 않습니다. ‘이 기기의 게스트 기록 가져오기’에서 미리보기 후 합칩니다.

시작·채점 시 시험 체크포인트도 전송합니다. 다른 기기에서 ‘최근 저장 시험 불러오기’를 눌러 같은 시험의 답안·선택지 순서를 이어갑니다. 각 기기의 탐색 위치는 별도로 저장됩니다. 두 기기에서 실제로 각각 선택·채점한 행동은 별개의 풀이로 집계됩니다.

미응시 학습은 **미응시 문제만 출제**를 체크한 뒤10·20·전체 시작 버튼으로 진행합니다. 체크를 해제하면 일반 학습입니다.

## 기존 기록 이전

1. 기존 HTML에서 **기록 백업(JSON)**을 내려받습니다. 기존 HTML 저장소를 삭제하지 마세요.
2. 새 앱에서 원하는 계정에 로그인합니다.
3. **기록 복원(JSON)**으로 파일을 선택하고 문항 수·증가할 풀이 횟수·미등록 ID·중복 제외 수를 확인합니다.
4. **미리보기 확인 후 합치기**를 누릅니다. 가져오기 직전 현재 기록도 자동으로 JSON 다운로드합니다.

원본의 저장소 키 `electrical_construction_mcq_v1`가 같은 출처의 브라우저에 존재하면 최초 실행 때 게스트 영역에 복사합니다. `file://`에서 쓰던 HTML과 새 HTTPS 사이트의 저장소는 서로 다르므로 이 경우 JSON 이전이 필요합니다. 가져오기 취소·검증 실패·트랜잭션 실패 시 기존 이벤트는 보존됩니다. 미등록 ID는 미리보기에 표시하며 자동으로 잘못 연결하지 않습니다.

구버전은 개별 이벤트가 없어 문항별 누적 정답·오답·정오답 불명 횟수의 최댓값으로 이전 기록을 합칩니다. 내보낸 시간만 다른 동일 백업도 중복 제외됩니다. 겹치는 구버전 백업끼리 합계가 단순히 더해지지 않습니다. 다만 구버전 백업이 이미 새 앱에서 생성한 이벤트를 포함하는지 자동 판별할 수 없습니다. 미리보기 증가량을 확인하고, 새 앱에서는 반드시 v3 JSON 백업을 사용하세요. v3는 이벤트 ID를 유지하므로 클라우드와 같은 기록도 중복 집계하지 않습니다.

## 새 문제 추가

`src/questions.json`에 새 객체를 추가합니다. 기존 q001~q189를 재번호 매기거나 다른 문제로 재사용하지 마세요. 새 ID는 `ec-2021-1-001`처럼 영구 식별자로 지정합니다. 선택지는 정확히 네 개, `correct`는 0부터 시작하는 정답 인덱스입니다. 원본 앱은 0만 채점했지만 새 앱은 0~3을 지원합니다.

```json
{
  "id": "ec-2021-1-001",
  "year": "2021-1회",
  "examYear": 2021,
  "round": 1,
  "category": "설비·배선",
  "originalQuestion": "확보한 원본 문제를 그대로 기록",
  "question": "객관식 변환 문제",
  "options": ["선택지1", "선택지2", "선택지3", "선택지4"],
  "correct": 1,
  "explain": "근거가 포함된 해설",
  "diagram": null,
  "caution": true,
  "source": {"file": "원자료명", "exam": "2021-1회", "originalTextAvailable": true},
  "verification": {"status": "needs-review", "notes": ["근거·검증 날짜 기록"]}
}
```

기존 자료에는 단답형 원문이 포함되어 있지 않아 `originalQuestion`은 `null`입니다. 원문을 추정해 채우지 않았습니다. 새 그림은 `src/app.js`의 `diagrams`에 고정 SVG 키로 추가하고 `diagram`에 연결합니다. 데이터 문자열을 임의 HTML로 실행하지 않습니다. 같은 관점·정답의 중복 문항을 추가하지 말고 출처·검증 상태를 남기세요.

```sh
npm run validate
npm test
npm run build
```

main에 반영하면 Pages 워크플로가 `public/`을 배포합니다. 기존 문항 보존 검사에 실패하면 배포하지 않습니다. 기존 문항 내용의 정정은 ID와 정답 인덱스를 유지하고 `src/question-corrections.json`에 날짜·요청 근거·필드별 before/after를 기록한 뒤 데이터에 반영하세요. 검사기는 기록된 정정만 허용하며 나머지 원본 필드는 그대로 검사합니다. 서비스워커가 새 버전을 준비하면 ‘새 버전 적용’ 버튼이 표시됩니다. 사용자가 누르기 전에는 진행 중 화면을 자동 교체하지 않습니다.

## 홈 화면 추가

- Android Chrome: 메뉴 → 홈 화면에 추가 또는 앱 설치.
- 삼성 인터넷: 메뉴 → 현재 페이지 추가 → 홈 화면.
- iPhone/iPad Safari: 공유 → 홈 화면에 추가.
- PC Chrome/Edge: 주소창의 앱 설치 아이콘.

최초 온라인 접속·캐시 준비 후 오프라인 학습이 가능합니다. Google 신규 로그인과 클라우드 전송에는 인터넷이 필요합니다. 재접속 시 미전송 기록을 자동 전송합니다. 실제 Android·iOS 기기의 설치·Google 로그인은 별도 확인이 필요합니다.
