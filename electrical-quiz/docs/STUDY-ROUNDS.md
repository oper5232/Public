# 회독별 미응시와 출제 제외

누적 풀이 이벤트는 그대로 두고, 선택한 회독보다 누적 풀이 횟수가 적은 문제를 미응시로 봅니다.

| 기준 | 미응시 | 완료 |
| --- | --- | --- |
| 1회독 | 누적0회 | 누적1회 이상 |
| 2회독 | 누적0~1회 | 누적2회 이상 |
| 3회독 | 누적0~2회 | 누적3회 이상 |

정답·오답 모두 풀이1회로 계산합니다. 실기에서 답만 입력하거나 모범답안만 보는 것은 풀이 횟수를 늘리지 않습니다. 새 시험에서 다시 채점하면1회를 추가하고, 이미 채점한 시험을 새로 열거나 새로고침하는 것은 추가하지 않습니다.

## 선택 방법

- **자동 선택**은 현재 모드·연도/회차·분야·실기 유형에 포함되는 문항의 최소 누적 풀이 횟수+1입니다. 선택 범위가 모두1회 이상이면2회독, 모두2회 이상이면3회독으로 바뀝니다. 처음부터 여러 번 푼 문제가 있어도 다른 문제의 미응시 기준을 올리지 않습니다.
- 자동 선택을 끄면 **미응시 기준 회독**에 양의 정수를 직접 입력할 수 있습니다. 특정 회독을 고정하면 완료 후 미응시0개가 표시됩니다. **다음 회독** 또는 결과 화면의 다음 회독 버튼으로 기준을 올릴 수 있습니다.
- 홈의 미응시 체크박스와 결과 화면의 미응시10/20/전체 버튼은 같은 기준을 사용합니다. 자동 선택에서는 마지막 미응시를 채우면 결과 버튼이 다음 회독 기준으로 바뀌고 기준 회독을 함께 표시합니다.
- 진행 중 시험은 시작할 때의 회독을 저장합니다. 홈·결과의 다음 출제 기준이 자동으로 올라가더라도 이미 채점한 시험의 회독·결과를 소급 변경하지 않습니다.
- 객관식과 실기는 누적 기록과 회독을 구분합니다. 관심 문제는 이전과 같이 공유합니다.
- 자동 회독은 동기화된 누적 기록에서 계산되므로 같은 범위를 고르면 다른 기기에서도 동일한 기준을 얻습니다. 자동/수동 선택은 계정·모드별 기기 설정에 보관하며, 저장된 시험의 회독 번호는 기존 시험 동기화에 포함됩니다.

## 기록 보존과 구현

- `src/retired-questions.json`의24개 ID는 출제·오답/관심 재시험·진행 중/원격 시험에서 제외합니다. `sources/retirement-report.json`에 사용자 지정 항목과 ID를 연결했습니다.
- 원본 문항·실기 답안269개와 기존 풀이 이벤트를 보관해 옛 백업의 ID를 계속 인식합니다. 사용자 풀이를 삭제하거나 횟수를 재설정하지 않습니다. 제외한 문제의 과거 기록도 누적 풀이·누적 정답률과JSON 백업에 유지하며CSV에서 출제 상태를 표시합니다.
- 오래된 시험은 표시할 때 제외 문항만 걸러서 남은 문항·위치·답안으로 이어갑니다. 모두 제외된 원격 시험은 이어풀기를 비활성화합니다. 원래 이벤트를 덮어쓰거나 삭제하지 않습니다.
- `src/study-rounds.js`가 회독 판정과 출제 가능한 문제/시험의 표시를 처리합니다. 기록 저장소와 가져오기는 전체269개 알려진 ID를 사용합니다.
- 기존 session 이벤트의 `session.studyRound`에 시험의 회독 번호를 저장합니다. 새 이벤트 종류나 Firestore 경로를 만들지 않으며, 기존 서버 규칙이 허용하는 session map의 선택 필드입니다. 서버 보안 규칙·유료 설정은 바꾸지 않았습니다.
- 과거 버전 앱의 미응시 기준은1회독입니다. 기기 간 같은 동작을 사용하려면 새 버전을 적용합니다. JSON 백업에 누적 기록이 있으므로 별도 회독 초기화나 기록 이전은 필요 없습니다.

## 검사

`npm run test:rounds`는 순수 함수6개 검사와 모바일 화면 자동 검사를 실행합니다. 2회독과3회독의 경계, 자동/수동 선택, 누적 기록·제외 문항의 백업, 객관식/실기 분리, 결과 바로가기, 오프라인 재접속, 기기 간 이벤트 가져오기 및 과거/원격 시험 필터를 확인합니다. 실제 Google 계정의 두 실물 기기를 이번 검사에서 새로 검증한 것으로 해석하지 않습니다.
