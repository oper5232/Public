# 실기 모드

홈 화면의 **학습 모드 → 실기 · 단답 / 빈칸 채우기**를 선택합니다. 단답형만, 빈칸형만 또는 혼합 출제가 가능합니다. 기존 회차·분야·10/20/전체·오답·관심 출제 기능을 그대로 사용합니다. **미응시 문제만 출제** 체크 후10·20·전체 시작 버튼을 누르면 선택한 모드·회차·분야의 미응시 문제만 출제합니다. 체크를 해제하면 응시 여부와 관계없이 일반 학습을 할 수 있습니다.

답안을 작성한 뒤 **모범답안 확인**을 누르고 핵심 내용·수치·단위를 비교하여 **맞았어요 / 틀렸어요**로 기록합니다. 자동 채점이나 공인 시험 채점 결과가 아닙니다. 답안 작성 또는 모범답안 확인만으로는 풀이 횟수가 증가하지 않습니다. 같은 시험에서 판정은 한 번만 저장하며 새 시험은 새로운 풀이로 집계합니다. 모범답안 확인 후에는 작성 답안을 변경할 수 없습니다.

작성 답안은 입력 시 IndexedDB에 저장하고, 입력을 멈춘 뒤·화면 이동 시 클라우드 전송용 체크포인트를 만듭니다. 로그인하면 기존 동기화 큐를 사용합니다. 다른 기기에서 **최근 저장 시험 불러오기 · 실기**를 눌러 답안과 판정 상태를 이어갑니다. 인터넷이 없으면 로컬에 보관하고 재접속 시 전송합니다. 다른 기기에서 최신 시험을 불러오면 현재 진행 시험이 바뀌므로 필요한 답안은 먼저 저장·백업하세요.

학습 현황·정답률·미응시·오답은 객관식과 실기를 별도로 계산합니다. 관심 표시는 공유합니다. v3 JSON 백업에는 두 모드의 기록과 저장된 답안 체크포인트가 함께 들어갑니다. 가져오기 미리보기의 풀이 합계도 두 모드 합계이며, 기존 v2 기록은 객관식으로 분류합니다. CSV는 현재 선택한 모드의 통계입니다.

## 자료와 ID

- 기존 `src/questions.json`의189개 ID·객관식 문항·정답·분류는 변경하지 않았습니다.
- `src/practical.json`은 총233개 ID에 연결된 단답150개/빈칸83개입니다. 원문 암기노트를 실기 질문으로 나누거나 문장·빈칸을 구성했습니다. 공식 시험지의 완전한 복제가 아닙니다.
- `sources/practical-notes.json`에 제공 노트의 회차별 발췌·정리, 연결 ID, 보완 필요 항목을 보관합니다. 실기 모범답안 아래에서 해당 발췌를 볼 수 있습니다. 보기 전에는 답을 드러내는 기존 개념도도 숨깁니다.
- 사용자가 22-1회가 맞다고 확인하여 마지막16문항(q174~q189)의 객관식·실기·출처 분류를2022-1회로 통일했습니다. 기존 파일의 회차 오기는 정정 목록에 기록하고 ID·선택지·정답 인덱스·학습 기록은 유지합니다.
- 마지막 할증/철거손실 표보다 앞선 명시적 정정 요청을 우선하여 옥외전선5%/2.5%, 옥외케이블3%/1.5%를 적용합니다.
- 2025-2회 절연물 최고허용온도는 제공 사진의 세 빈칸으로 추가했고, KEC 표 232.5-1과 대조했습니다. 두 회차 그림기호는 제공 사진을 바탕으로 시각 식별 문제로 추가했습니다. 동일한 배전반 기호는 같은 ID를 공유합니다. 단위 생략·오기 의심·설명필요 표시는 문항별 주의사항에 남겼습니다. 공식 최신 규정 대조를 완료한 것으로 표시하지 않습니다.

## 유지관리

실기 항목은 `kind`(short/blank), `prompt`, `fields`(label/answer), `basisAnswer`, `source`, `notes`로 구성합니다. `basisAnswer`는 연결된 객관식 정답을 기록해 한쪽만 바뀌었을 때 빌드를 실패시킵니다. 새 질문은 원자료 발췌와 출처 ID를 함께 연결하세요. 새 객관식 ID는 기본 단답 방식으로도 출제되지만, 선택지 의존 문장은 편집자가 실기 질문을 따로 작성해야 합니다.

`practical_` 접두사의 시험 ID로 실기 이벤트를 구별합니다. 기존 Firestore 이벤트 스키마를 유지하며, 실기 이벤트의 `choice`는 정오답 호환 코드입니다. 실제 작성 텍스트는 `session.drafts`에 저장하고 `session.revealed`로 모범답안 확인 상태를 보관합니다. 기존 보안 규칙의 소유자 제한·불변 이벤트 정책을 유지합니다. 새 모드가 없는 오래된 앱은 두 모드 통계를 합산할 수 있으므로 PWA 업데이트를 적용하세요.

작성 답안 한 칸은2,000자, 세션 전체는UTF-8 기준700KB로 제한합니다. 답안 체크포인트도 무료 Firestore 문서 저장량·쓰기 할당량을 사용합니다. 오래된 이벤트를 직접 삭제하지 말고 먼저 v3 JSON 백업을 보관하세요.

## 2021년 자료 추가(2026-10-23)

2021-1·2·4회 제공 노트에서 새로운29문항을 추가하고 기존15개 ID에 출처 회차를 연결했습니다. 회차 필터는 최초 등록 회차와 추가 출처 회차를 모두 포함합니다. 같은 ID는 회차가 달라도 동일 기록을 공유하며 전체 문항 수에 중복 집계하지 않습니다. 회차별 진행률을 합하면 공유 문항 때문에 전체 고유 문항 수보다 클 수 있습니다.

- 2021-4회: 신규13개 + 기존9개 = 출제 가능22개.
- 2021-2회: 신규8개 + 기존3개 = 출제 가능11개.
- 2021-1회: 신규8개 + 기존3개 = 출제 가능11개.
- 2021년 경간 노트의 “170kV 이하”와 기존 질문의 “170kV 미만” 차이는 질문을 임의 변경하지 않고 회차별 확인 메모로 남겼습니다.
- EL램프 특징 등은 제공 학습노트 기준이며 공식 최신 자료 검증 완료로 표시하지 않습니다.

원문 보관은 `sources/2021-user-notes.md`, 추가·중복 연결 목록은 `sources/2021-import-report.json`입니다. 새 출처는 기존 문항의 `appearances`에 exam/sourceId/file을 추가하고 `sources/practical-notes.json`에 해당 발췌와 ID를 연결합니다. 같은 관점·같은 답의 문항을 다시 만들지 마세요. 새 질문은 영구 ID를 발급하고 객관식과 실기 데이터를 함께 추가한 뒤 빌드·시험을 실행하세요.

2026-10-23 여섯 사진 추가: 당시229개 ID(단답146/빈칸83). 문제용 기호·번호 도면은 답안 공개 전부터 표시합니다. 내장애자는 번호별 명칭, 눈부심은6가지, 콘덴서COS는50kVA 미만으로 정정했습니다. [전사·검토](../sources/2026-10-23-six-photos.md).

추가 교재 사진 반영 후 현재233개 ID(단답150/빈칸83)입니다.2022-2회 기호4개를 추가했고, 콘덴서 보호 실기에서는 번호의 명칭·역할을 작성하며 등급III는 정의 전체를 연습합니다. [대조 내역](../sources/2026-10-23-capacitor-luminaires.md).

## Book 4.xlsx 회로·계산 문제

Book4 최초 추가 때269개 문항(단답186/빈칸83)이었습니다. 후속 사용자 지정으로 현재245개(단답162/빈칸83)를 출제합니다. 회로 작성형은 논리식·단자쌍·분기 구조를 작성하고 **모범답안 확인** 뒤 도면과 대조해 직접 판정합니다. 출제 도면과 모범 회로에서 **도면 확대**를 눌러 확대·스크롤할 수 있습니다. 계산 문제에는 주어진 표가 함께 표시되며 풀이 과정과 단위를 답안에 작성합니다. 작성 답안·정오답은 기존 저장 체계를 사용합니다. 새 시험에서 다시 작성한 답안은 이전 시험의 답안을 자동 복사하지 않습니다.
