자료 범위와 유의사항

제공한 「공사기사 기출문제 단답형.txt」 및 추가로 보내준 2022년 2·4회 자료에 기록된 2022-2회·4회 및 2023-1회~2026-2회 내용을 토대로 객관식으로 변환했습니다. 선택지는 학습을 위해 작성한 오답 보기입니다.

2022-2 자료와 2024-2 자료의 옥외 케이블 할증률이 2.5% / 3%로 서로 다릅니다. 두 원문을 회차별로 유지했으며, 최신 표준품셈 검증 전에는 같은 기준으로 취급하지 마세요.

법령·KEC·표준품셈 수치는 원본의 암기값을 기준으로 하며 최신 개정 여부를 검증하지 않았습니다. 법규 문제에는 '기준 확인' 표시가 붙습니다. 텍스트에 실제 도면이나 기호 모양이 없는 항목은 임의의 정식 기호를 복원하지 않았습니다. 삽화는 이해를 돕는 개념도입니다.

홈 화면에서 학습하기

Android Chrome: 메뉴 → 홈 화면에 추가 또는 앱 설치. 삼성 인터넷: 메뉴 → 현재 페이지 추가 → 홈 화면. iPhone/iPad Safari: 공유 → 홈 화면에 추가. PC Chrome/Edge: 주소창의 설치 아이콘을 누르세요. 최초 온라인 접속 후 캐시가 준비되면 오프라인 학습이 가능합니다.

로컬 기록은 IndexedDB에 저장됩니다. 브라우저 데이터 삭제·시크릿 모드 종료 시 로컬 기록이 지워질 수 있으므로 JSON 백업과 클라우드 동기화를 사용하세요. 기존 파일의 학습 기록은 기존 HTML에서 JSON으로 내보낸 뒤 이 앱에서 가져오세요.

정답을 선택하면 즉시 채점되고 해설이 표시됩니다.
